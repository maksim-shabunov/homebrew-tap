# maksim-shabunov/tap

Homebrew casks for my macOS apps.

```sh
brew install --cask maksim-shabunov/tap/wildcard
```

| Cask | What it is |
| --- | --- |
| [caret](https://github.com/maksim-shabunov/caret) | Fixes text typed on the wrong keyboard layout |
| [wildcard](https://github.com/maksim-shabunov/wildcard) | Sets which app opens which kind of file, a whole category at a time |

Please open issues against the app's own repository rather than this one.
